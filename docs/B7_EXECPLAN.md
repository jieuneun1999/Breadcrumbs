## Recovery design alternatives

Replacing the existing state.txt with only a new pointer would break genuine old
readers, fixtures and existing corruption/ACL checks. Keeping only a mirror without
a generation pointer would not supply explicit transaction identity. Selected design
retains state.txt as the validated current snapshot plus immutable generation bytes
and an atomic current manifest. Load requires agreement rather than silently choosing
one copy. A disagreement, unfinished stage or newer uncommitted generation is a
recovery boundary. Recovery requires exact candidate acknowledgement and preserves
interrupted bytes. The container version is separate from canonical v1/v2/v3.

All old versions stay byte-compatible. B7C alone may introduce canonical format 4
for manual-origin records/preferences/review acknowledgements. Frozen Master and
First-Import documents stay unchanged; extensions are documented in separate ADRs.
